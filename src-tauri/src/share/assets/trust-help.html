Trust this device

Install Readaity Share's certificate so your browser stops warning about this connection. One time per device. Check the fingerprint against the one shown in Readaity's Sharing settings first.

Download the certificate

iPhone / iPad

  1. Open /trust in Safari and allow the profile download.
  2. Settings → General → VPN & Device Management → install the profile.
  3. Settings → General → About → Certificate Trust Settings → turn it on.

Android

  1. Download from /trust.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Pick the downloaded .pem file.

Windows

  1. Save the file from /trust, then double-click it.
  2. Install Certificate → Local Machine → Place in Trusted Root Certification Authorities.

macOS

  1. Open the downloaded file in Keychain Access, adding it to the System keychain.
  2. Double-click it → Trust → set When using this certificate to Always Trust.

Firefox (any system)

  1. Settings → Privacy & Security → Certificates → View Certificates → Import.
  2. Select the file and tick Trust this CA to identify websites.
